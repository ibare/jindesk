정한 것

자리
목록 칸의 과목마다 맨 위에 "개념 지도" 줄을 둔다. 고르면 내용 칸에 지도가 열린다. 목록의 개념을 고르면 지금처럼 학습 페이지가 열린다.
배치
둘 다 둔다. "배우는 순서"는 선수 개념이 몇 겹 쌓였는지로 칸을 나누고, "목차대로"는 강의 계획 항목마다 한 칸이다.
그리는 것
이 과목의 개념, 아직 없는 개념(점선), 켜면 다른 과목의 선수 개념. 과목 사이 연결(links)은 배우는 순서가 아니라서 그리지 않고, 모아 보기의 과목 사이 연결 화면에 둔다.
고르기
노드를 고르면 거슬러 올라가는 선수 개념 전체(파랑)와 이어지는 개념 전체(보라)가 밝아진다. 학습 페이지는 아래 단추로 열거나 노드를 두 번 눌러 연다.
갱신
작업이 끝날 때마다 다시 읽는 개념 목록에서 지도를 그때그때 계산한다. 따로 저장하는 파일은 없다. 오늘 정리된 개념(provenance.job 날짜가 오늘)에는 "새로"가 붙는다.
아직 아닌 것
아직 없는 개념이 나중에 생겨도 지도에서 저절로 이어지지 않는다. 지도 다음에 개념 정리 쪽에서 고친다. 그 전까지는 같은 제목의 점선 노드와 실제 노드가 함께 보일 수 있다.
