# 시안

`index.html` 한 파일이다. 브라우저로 열면 된다.

- 수식(MathJax)과 글꼴(Google Fonts)을 CDN 에서 받으므로 인터넷이 필요하다. 실제 앱은 KaTeX 와 글꼴을 번들에 넣고 네트워크를 쓰지 않는다(`../PAGES.md`의 렌더러).
- 밝은 화면과 어두운 화면 모두 맞다. 시스템 설정을 따른다.
- 내용은 모두 예시다: 자료 이름, 코멘트, 답글, 쪽 번호, 강의 계획 코드. 강의 계획 코드(Physics A.1·B.5, Chemistry R1.3, Math AA AHL 5.12)는 최근 가이드를 기억에 기대어 적은 것이다. 실제 목차는 목차 만들기가 근거 문서에서 만든다.
- 시안에서 남긴 코멘트와 요청은 저장되지 않는다. 새로 고치면 사라진다.

## 탭

| 탭 | 무엇 |
|---|---|
| 앱 화면 | Mac 창 하나: 사이드바, 강의 계획 목록, 학습 페이지, 인스펙터. 학습 페이지 넷: Math AA AHL 5.12 첫 원리로 미분, Physics A.1 투사체 운동, Physics B.5 직렬·병렬 회로, Chemistry R1.3 에탄올의 연소 |
| 구조 | 원칙, 작업 흐름, 강의 계획 목차를 만드는 방식, 그림이 만들어지는 길, 부분 다시 만들기, 맥 두 대와 데이터 폴더와 업데이트, 작업 종류, 데이터 배치, 정할 것 |
| 블록 어휘 | 블록마다 에이전트가 쓰는 것, 러너 검사, 렌더러가 그리는 것과 명세 예. 바뀌기 전의 방식이다(아래 "문서와 다른 점") |

## 해 볼 것

- 문단 끝의 `한`: 그 문단 아래에 한국어가 펼쳐진다. 페이지 머리의 "모두 접기"로 한 번에 접는다.
- 점선 밑줄 용어에 포인터를 올리면 한국어 뜻이 보인다.
- `✎`: 그 문단의 코멘트 스레드가 열린다. 메모, 질문, 이상해요 가운데 하나를 골라 남긴다.
- `↻`, 블록 머리의 "↻ 다시 만들기": 다시 만들기 시트가 열린다. 방식을 고르면 놓이는 곳, 그대로인 것, 검사가 바뀐다.
- 투사체 페이지 첫 문단의 `쉽게`: 곁 설명과 그 검사 결과가 펼쳐진다.
- 미분 페이지 풀이 3단계의 "새 판 · 비교": 이상해요 코멘트에서 시작된 새 판 후보다. 받아들이면 그 단계와 그 번역만 바뀐다.
- 슬라이더와 단추:
  - 할선이 접선이 되는 그래프
  - 투사체 실험 (지구·달, 여각 궤적)
  - 회로 전류
  - 반응식 균형 맞추기
  - 촉매 에너지 도표
  - 전자 배치
- 출처 칩("slides · 12"): 원래 자료 쪽 보기가 열린다(시안은 축소 그림).
- "자료 넣기": 과목만 고르고, 같은 내용의 자료가 빠지는 모습.

## 문서와 다른 점

문서가 맞다. 시안은 화면의 느낌과 흐름을 보이기 위한 것이다.

- 시안의 단위 id(`proj-p1`, `deriv-s3`)는 화면용 표기다. 문서의 id 는 페이지 안에서 `p1`, `s3`이고, 밖에서는 `<개념 id>#p1`이다(`../DATA.md`).
- 블록 어휘 탭과 구조 탭의 "그림이 만들어지는 길"은 바뀌기 전의 방식이다. 지금은 그림과 인터랙션을 에이전트가 코드로 짜고, 러너는 돌아가는지만 본다(`../DECISIONS.md` 18, `../PAGES.md`의 그림 블록). 앱 화면 탭의 그림들은 그렇게 만든 그림의 예로 읽는다.
- 구조 탭의 보내기 묶음과 살펴보기는 두지 않기로 했다(`../DECISIONS.md` 20).
- 구조 탭은 요약이다. 자세한 것은 각 문서에 있다.
