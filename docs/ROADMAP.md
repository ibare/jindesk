# 진행 단계

배포와 업데이트를 먼저 만든다. 그래야 그 뒤의 모든 고침이 자동 업데이트로 학생 맥에 간다. 데이터 모양(id, 판, 해시, 스키마 버전)도 처음부터 둔다. 나중에 붙이면 그때까지 쌓인 데이터를 다룰 길이 없다.

## 0단계: 뼈대와 배포

- 저장소와 XcodeGen 정의(`mac/project.yml`). Developer ID 서명과 hardened runtime 을 쓴다.
- Assayer 엔진 옮기기: Agent, Guard(`jindesk-guard`), Process, Config(키체인), Engine(대기열, 잠금, 사용량, 지침 넣기), Util. 목록은 `ARCHITECTURE.md`에 있다.
- 데이터 폴더 고르기와 iCloud 경고, 캐시와 앱 지원 폴더, 데이터 폴더 잠금.
- `meta/schema.yaml`, 마이그레이션 실행기 뼈대(백업, 사본, 검증, 바꿔 끼우기, 이어 하기), `jindesk migrate --check`.
- Sparkle 연결, 작업 중 설치 미루기, `mac/scripts/release.sh`.
- 환경 점검(`doctor`), 관리자 설정, 키체인 토큰.
- 백업 만들기.
- 화면 찍기(Assayer 의 SnapshotDriver).
- **끝나는 기준.** 0.1.0 을 릴리즈해 학생 맥에 설치하고, 0.1.1 을 릴리즈했을 때 학생 맥이 작업이 없는 때에 스스로 업데이트한다.

## 1단계: 과목 하나를 끝까지

과목 하나(예: Physics HL)로 자료에서 학습 페이지까지 이어지게 한다.

- 목차 만들기.
- 자료 넣기: Keynote 변환, PDFKit 글자층, Vision 글자 인식, 쪽 이미지.
- 자료 읽기: 1차·2차, 학생 독자 시험, 읽은 쪽 세기.
- 개념 정리.
- 학습 페이지 만들기, 번역, 용어 어휘.
- 렌더러: `math`, `derivation`, 강조 상자, 확인 문제, 연결. 출처 칩과 원래 자료 보기, 문단 곁 한국어.
- 그림 블록: 블록 틀, 공통 부품 첫 묶음, 돌아가는지 확인, 라이브러리 받아 두기(`PAGES.md`).
- 단위 id·판·`from` 해시, `history.jsonl`, `directives.jsonl`. 기능 없이 파일과 모양만 둔다.
- SQLite 색인과 검색.
- JSON Schema 검증기. 러너 검사와 마이그레이션 검증이 `schemas/<버전>/`으로 파일을 본다. 0단계의 마이그레이션 검증은 YAML 이 읽히는지, `kind`와 `v`가 있는지까지만 본다.
- **끝나는 기준.** 학생이 받은 실제 자료 몇 개로 페이지가 만들어지고, 출처를 눌러 원래 쪽으로 갈 수 있다. 한국어를 문단마다 펼칠 수 있다.

## 2단계: 그림과 대화

- 공통 부품 늘리기. 그림 블록들이 되풀이해 짜는 것(그래프 읽기, 시간 흐름 조작, 벡터 화살표 같은 것)을 부품으로 옮긴다.
- 코멘트(메모, 질문, 이상해요)와 물어보기.
- 과목 늘리기(Math AA HL, Chemistry SL …), MYP 단원 안내.

## 3단계: 부분 다시 만들기와 관점

- 부분 다시 만들기: 모든 방식, 격리 검증, 새 판 비교, 고치기(`REGENERATION.md`).
- 관점 붙이기와 레퍼런스 찾기, 과목 사이 연결 화면.

## 4단계: 확인 문제

- 확인 문제, 푼 기록, 다시 볼 개념.

## 늘 하는 것

- 작업 지침을 바꾸면 파일 위의 버전을 올리고 릴리즈 노트에 적는다.
- 데이터 모양을 바꾸면 새 스키마, 마이그레이션 단계, 시험 표본, 학생 백업 사본으로 하는 `--check`를 함께 만든다.
- 공통 부품을 바꾸면 하위 호환을 지킨다. 깨지는 변경이면 부품 판을 올리고, 옛 판을 쓴 그림 블록이 낡은 것이 되어 다시 만들어진다.
