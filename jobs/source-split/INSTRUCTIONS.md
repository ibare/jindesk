# 자료 나누기 지침

지침 버전: `0.1`

이 문서는 자료 나누기 에이전트가 따르는 유일한 지침이다. 에이전트는 IB 학생 한 명이 학교에서 받은 파일이 수업 몇 개를 담고 있는지 보고, 여러 수업이 들어 있으면 수업마다 쪽 범위를 나눈다. 러너가 나눈 수업마다 자료와 묶음을 따로 만들고, 뒤의 작업(자료 읽기, 개념 정리)은 수업 하나씩 다룬다. 한 번에 읽고 정리하는 양을 수업 하나로 두기 위해서다. 과목은 가리지 않는다.

## 1. 원칙

1. **자료가 스스로 표시한 수업 경계로만 나눈다.** "Class 3 of 21", "Lesson 4", "Week 2 · Day 1", "Session 5"처럼 자료가 수업(차시)이 바뀐다고 적어 둔 곳이다. 차시 표지, 차시마다 되풀이되는 시작 쪽(Do Now, Starter, Learning Outcome 같은 머리)도 경계의 단서다.
2. **내용으로 짐작해 나누지 않는다.** 주제가 바뀌는 것 같아도 자료가 수업 경계를 표시하지 않았으면 나누지 않는다. 수업 하나가 여러 주제를 다룰 수 있다.
3. **수업 하나짜리는 나누지 않는다.** 수업 하나의 슬라이드, 워크시트, 단원 계획서, 시험지, 판서 사진은 그대로 둔다. 경계가 분명하지 않아도 나누지 않는다. 나누지 않아도 뒤의 작업은 돈다.
4. **주(week)가 아니라 수업(차시)이 단위다.** 주 하나에 수업이 여러 개 있으면 수업마다 나눈다. 두 차시를 잇는 수업(Double, Part 1·Part 2)도 자료가 차시를 따로 표시했으면 따로 나눈다.
5. **모든 쪽이 어느 수업에 든다.** 단원 표지, 목차처럼 첫 수업 앞에 있는 쪽은 첫 수업에 붙인다. 수업 사이에 끼인 쪽(다음 주 표지 같은 것)은 뒤 수업에 붙인다. `index.md`의 이어 채운 쪽 묶음은 가르지 않는다.
6. **질문하지 않는다.** 무인으로 돈다. 판단이 갈리면 나누지 않는 쪽을 고르고 기록에 적는다.

## 2. 작업 공간

```
input/request.md                        묶음 id, 메모, 볼 자료 표(자료 id, 원본 파일 이름, 쪽 수, 꼬리표)
input/sources/<자료 id>/index.md         쪽 목록: 쪽마다 글자 수, 글자층을 만든 방법, 이어 채운 쪽 묶음
input/sources/<자료 id>/text.md          쪽마다의 글자층 ("## 3쪽" 머리 아래에 그 쪽의 글자)
input/sources/<자료 id>/pages/0001.png   쪽 이미지
out/                                    여기에만 쓴다
work/                                   작업 메모 (써도 되고 안 써도 된다)
```

## 3. 보는 방법

1. `input/request.md`와 자료마다 `index.md`를 읽는다.
2. `text.md`를 처음부터 끝까지 읽고 수업 경계를 찾는다. 글자층은 수식이 깨질 수 있지만 경계를 찾는 데는 충분하다.
3. 경계 근처의 쪽이 애매하면(글자가 거의 없는 쪽, 그림만 있는 쪽) 그 쪽 이미지를 본다. 모든 쪽 이미지를 볼 필요는 없다.

## 4. `out/split.json`

```json
{
  "sources": [
    {
      "source": "20261019-5e0a71c9",
      "lessons": [
        { "pages": [1, 9], "title": "Class 1: What is momentum?" },
        { "pages": [10, 17], "title": "Class 2: Impulse" }
      ]
    },
    { "source": "20261019-91b2c3d4", "lessons": [] }
  ]
}
```

- 볼 자료마다 항목 하나다. 나누지 않으면 `lessons`는 빈 목록이다.
- `pages`: 그 수업의 첫 쪽과 마지막 쪽. 수업은 쪽 차례대로 둔다. 첫 수업은 1쪽에서 시작하고, 다음 수업은 앞 수업의 마지막 쪽 다음 쪽에서 시작하며, 마지막 수업은 자료의 마지막 쪽에서 끝난다.
- `title`: 수업의 영어 이름. 자료가 쓴 차시 표시와 그 수업의 제목을 살린다(예: "Class 3: Conservation of momentum"). 한글을 쓰지 않는다.

## 5. `out/report.md`

한국어로 짧게 쓴다. 자료마다 나눴는지, 무엇을 수업 경계로 봤는지, 나누지 않았으면 왜인지, 판단이 갈린 곳.

## 6. 러너 검사

- `out/split.json`이 JSON 으로 읽히고, 볼 자료마다 항목이 있다.
- 나누면 수업이 둘 이상이고, 쪽 범위가 1쪽부터 마지막 쪽까지 빈틈과 겹침 없이 차례로 덮는다.
- 이어 채운 쪽 묶음을 가르지 않는다.
- 수업마다 영어 이름이 있고, 한글, 한자, 일본어가 없다.

틀리면 같은 세션에서 문제 목록을 받고 한 번 고쳐 쓴다. 그래도 틀린 자료는 나누지 않는다.
