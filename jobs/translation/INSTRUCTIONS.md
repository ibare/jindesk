# 번역 지침

지침 버전: `0.5`

이 문서는 번역 에이전트가 따르는 유일한 지침이다. 에이전트는 학습 페이지의 영어 단위를 한국어로 옮긴다. 한국어는 페이지 전체를 바꾸는 판이 아니라, 학생이 문단마다 곁에 펼쳐 보는 층이다. 학생은 영어로 수업을 듣는 한국 학생이고, 영어 문단을 읽다가 막힐 때 한국어를 펼친다.

## 1. 원칙

1. **빠짐도 더함도 없이 옮긴다.** 영어 단위에 있는 내용을 모두 옮기고, 없는 내용을 더하지 않는다. 설명을 덧붙이거나 줄이지 않는다.
2. **수식은 그대로 둔다.** `\( … \)`와 `\[ … \]` 안의 TeX 는 한 글자도 바꾸지 않고 같은 자리에 둔다. 수식 안의 영어 낱말(`\text{…}`)도 그대로 둔다.
3. **숫자는 그대로 둔다.** 수식 밖의 숫자를 영어와 같은 숫자로 쓴다. 영어가 낱말로 쓴 수(two, three)는 한국어도 낱말(둘, 세)로 쓴다. 숫자를 더하거나 빼지 않는다.
4. **용어는 어휘를 따른다.** `input/glossary.yaml`에 있는 영어 용어가 나오면 정해진 한국어로 옮긴다. 같은 낱말이 다른 뜻으로 쓰였으면(예: 평균의 mean 과 "what it means"의 동사 mean) 어휘를 따르지 않고 그 뜻대로 옮긴다. 처음 나올 때는 `로그(logarithm)`처럼 영어를 괄호에 함께 써도 된다. 학생이 영어 수업의 용어와 이어 볼 수 있게 한다.
5. **한국 교과서의 말을 쓴다.** 어휘에 없는 용어는 한국 중고등 교과서에서 쓰는 말로 옮긴다. 그런 용어는 `terms`에 영어와 한국어를 함께 적어 어휘에 더하게 한다.
   - `terms`에는 그 과목의 전문 용어만 넣는다(예: logarithm, index form, asymptote, enthalpy). power, unknown, value, number 처럼 일상에서도 쓰는 낱말은 넣지 않는다. 어휘에 든 용어는 페이지마다 정해진 한국어로 옮겨야 하므로, 넓게 넣으면 번역이 묶인다.
6. **한국어로 쓴다.** 한자, 일본어, 중국어를 섞지 않는다. 영어 문장을 남기지 않는다. 용어를 괄호로 함께 쓰는 것은 된다.
7. **문체.** "~다"로 끝나는 설명문이다. 존댓말과 반말을 섞지 않는다.
8. **글 모양을 지킨다.** 빈 줄로 나뉜 문단, `**굵게**`, `*기울임*`, `- ` 나열을 영어와 같게 둔다.
9. **배우는 외국어는 그대로 둔다.** 영어 단위에 나온 영어가 아닌 언어의 낱말과 문장(외국어 과목의 예문, 활용, 낱말 목록)은 옮기지 않고 같은 자리에 같은 철자로 둔다. 괄호 안으로 옮기거나 차례를 바꾸지 않는다. 그 뒤에 붙은 영어 뜻만 한국어로 옮긴다: `*Ayer comí paella.* (Yesterday I ate paella.)` → `*Ayer comí paella.* (어제 나는 파에야를 먹었다.)`. 그 외국어 낱말은 `terms`에 넣지 않는다.
10. **질문하지 않는다.** 무인으로 돈다.

## 2. 작업 공간

```
input/targets.json    옮길 단위: [{ "id": "p1", "kind": "para", "text": "…" }]
input/page.yaml       페이지 전체 (맥락용. 옮길 단위만 옮긴다)
input/glossary.yaml   이 과목의 용어 어휘 (아직 없으면 terms 가 비어 있다)
out/                  여기에만 쓴다
```

## 3. `out/layers.json`

```json
{
  "units": {
    "p1": "로그는 \"몇 제곱인가?\"에 답한다. \\(a^y = x\\)이면 \\(\\log_a x = y\\)이다. …",
    "n2": "\\(\\log_a(x + y)\\)는 \\(\\log_a x + \\log_a y\\)가 아니다. …"
  },
  "terms": [{ "en": "logarithm", "ko": "로그" }, { "en": "base", "ko": "밑" }]
}
```

- `units`: `input/targets.json`의 단위마다 하나씩, 그 id 로 한국어를 둔다.
- `terms`: 이번에 옮긴 용어 가운데 어휘에 없던 것. 영어는 영어 글에 나온 표기 그대로, 한국어는 옮긴 말 그대로.
- JSON 안이므로 TeX 의 역슬래시는 두 번 쓴다.

## 4. 러너 검사

단위마다 본다. 틀리면 같은 세션에서 문제 목록을 받고 한 번 고쳐 쓴다. 그래도 틀린 단위는 넣지 않고 다음에 다시 옮긴다.

- 단위마다 한국어가 있고, 한자와 일본어가 없다.
- 수식이 영어와 같다 (개수와 내용).
- 수식 밖의 숫자가 영어와 같다.
- 영어 문장이 남지 않았다 (괄호 밖에 영어 낱말이 여섯 개 이상 이어지면 남은 것으로 본다. 모두 대문자인 단추 이름과 약어는 세지 않는다. 영어가 아닌 언어의 글은 세지 않는다).
- 어휘에 있는 영어 용어가 나오는 단위에는 정해진 한국어가 들어갔다. 러너는 낱말만 보고 알리므로, 다른 뜻으로 쓰인 낱말이면 고쳐 쓰지 않고 그대로 둔다. 고쳐 쓴 뒤에는 이 검사로 막지 않고 기록에만 남긴다.
- 길이가 영어와 너무 다르지 않다.
